Privacy policy

rclone-personal OAuth client · last updated 23 November 2026

Who this covers

rclone-personal is a single-user OAuth client created by one individual for their own laptop. The only Google Account that can authorise it is the owner's. There are no other users, so there is no third-party data to protect and no data collected about anyone else.

What Google user data is accessed

  • Files and folders in the owner's own Google Drive, via the Drive API (scope drive), in order to read and write backups.
  • The Google Account's email address, used only to identify which Drive to address.
  • Nothing else. No Gmail, Calendar, Contacts, Photos, or location data.

How the data is used

Exclusively to copy files from the owner's laptop to the owner's Drive and to restore them on request. No analysis, no profiling, no aggregation.

Storage and encryption

Files are encrypted on the laptop with a key that never leaves the laptop and is never sent to Google. Uploaded objects therefore appear in Drive as ciphertext under obfuscated filenames. Where files are overwritten or deleted locally, a previous copy may be retained on Drive in a dated archive folder so that an accidental deletion can be undone.

Sharing and third parties

Data obtained through the Drive API is not transferred to, shared with, or sold to any third party, is not used for advertising, and is not used to develop, improve or train machine learning or AI models. The only parties involved are the owner and Google, as the storage provider.

Retention and deletion

Backups remain in the owner's Drive until the owner deletes them. Deleting a file in Drive removes it; revoking the client's access in the Google Account permissions page ends all API access immediately. Archived versions are kept only so that accidental local deletions are recoverable.

Limited Use disclosure

This client's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
