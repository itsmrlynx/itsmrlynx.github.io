rclone-personal

A private, single-user Google Drive OAuth client

What this is

rclone-personal is a Google Cloud OAuth client belonging to one person, used to run rclone on their own laptop. It backs up that laptop's own files to that same person's own Google Drive account. It is not a product, has no users other than its owner, and is not distributed or offered for sign-in to anyone else.

What it does with Google data

It calls the Google Drive API to list, upload and download files inside the owner's own Drive. Nothing else: no Gmail, no Calendar, no Contacts, no profile data beyond the account identity needed to address the Drive.

Files are encrypted on the laptop before upload, so the Drive account stores ciphertext with obfuscated filenames. Google never receives plaintext copies of the backed-up files.

Data sharing

None. No data obtained through the Drive API is transferred to any third party, used for advertising, used to train models, or sold. See the privacy policy.

Source

rclone is open source: github.com/rclone/rclone. The backup job is a small shell script driven by a systemd timer on the owner's machine.
